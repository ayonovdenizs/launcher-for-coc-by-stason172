# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
нумерация — [Semantic Versioning](https://semver.org/lang/ru/).

Релизы собираются автоматически: тег `vX.Y.Z` запускает workflow
[Release](.github/workflows/release.yml), который собирает `Launcher-CoC.exe`
и создаёт GitHub Release с описанием из этого файла.

## [1.1.0] — 2026-09-15

### Добавлено

- **Автосборка `.exe`** через GitHub Actions: `Launcher-CoC.exe` собирается
  PyInstaller на `windows-latest` и публикуется в релизах — пользователю
  больше не нужен установленный Python (#11).
- Артефакт сборки при каждом пуше и pull request: файл можно скачать со
  страницы Actions и проверить без установки Python.
- **Атмосферный фон в стиле Зоны**: безрамочное окно с собственным заголовком,
  кнопками «свернуть/закрыть», перетаскиванием за заголовок (#8).
- **Иконка приложения** (`assets/icon.ico`, 16…256 px) для окна, панели задач
  и собранного `.exe`.
- Плавные анимации: подсветка кнопок при наведении, появление окна.

### Изменено

- Дизайн интерфейса переработан: тёмная «зональная» палитра, акцентная кнопка
  запуска, подписи режимов, статусная строка с состояниями (обычный/успех/ошибка).
- Кнопка «ОБНОВЛЕНИЕ» больше не заглушка: лаунчер в фоне проверяет последний
  релиз через GitHub API, сообщает о новой версии и открывает страницу релиза.
- Код разбит на пакет `launcher` (`paths`, `options`, `runner`, `updates`, `ui`),
  точка входа — `launcher_coc.py`.
- CI: `flake8` заменён на `ruff`, тесты — `pytest` (34 теста), сборка и тесты
  гоняются на каждый push и pull request.

### Удалено

- Файлы IDE (`.idea/`) больше не отслеживаются репозиторием.

## [1.0.0] — 2026-09-14

### Добавлено

- Первая версия лаунчера на **Python 3 + PySide6 (Qt 6)**: запуск игры,
  отладочный запуск (`-dbg`), фаст-запуск для слабых ПК, менеджер модов,
  настройки игры.
- Проверка наличия файлов перед запуском и понятные сообщения об ошибках.
- Логирование в `launcher.log`.
