# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
нумерация — [Semantic Versioning](https://semver.org/lang/ru/).

Релизы собираются автоматически: тег `vX.Y.Z` запускает workflow
[Release](.github/workflows/release.yml), который собирает `Launcher-CoC.exe`
и создаёт GitHub Release с описанием из этого файла.

## [1.2.0] — 2026-09-19

### Добавлено

- **Настройка лаунчера файлом `config.launcher`** — лаунчер больше не привязан
  к конкретному моду: имя, шапка окна, подпись, акцентный цвет, ширина окна,
  своя иконка и фон, запускаемые файлы, проверяемые файлы, репозиторий
  обновлений и весь список кнопок описываются в конфиге.
- Кнопки четырёх типов: `run` (exe/cmd/bat с аргументами), `url` (ссылка),
  `folder` (папка сохранений, лог движка, `fsgame.ltx`), `update` (проверка релиза).
- Гибкость на уровне кнопки: `hide_if_missing` (скрыть, если файла нет),
  `keep_open`, `accent`, свой `required_files`.
- Формат JSONC: комментарии `//` и `/* */`, висячие запятые, понятные ошибки
  с путём, строкой, подсказкой и фрагментом кода; неизвестные поля попадают
  в `launcher.log` как предупреждения.
- Флаги командной строки: `--check-config` (проверка конфига для CI и авторов
  модов), `--create-config` (образец), `--config`, `--version`.
- Диалоги запуска: нет файла — предложат «Создать пример» и «Открыть папку»,
  ошибка в файле — «Открыть файл» с подробностями и примером структуры.
- Пример настройки для стороннего мода — `examples/other-mod/config.launcher`,
  полное описание формата — `docs/CONFIG.md`.

### Изменено

- Логика разбита на модули `launcher/config.py`, `options.py`, `runner.py`,
  `console.py`; акцентный цвет интерфейса считается из конфига.
- Список режимов запуска больше не «зашит» в код: он читается из конфига,
  порядок кнопок в файле = порядок в окне, а высота окна подстраивается под
  число кнопок (при нехватке места появляется прокрутка).
- Имя `.exe` можно переопределить при сборке (`COC_EXE_NAME`), CI принимает
  это параметром — форки могут назвать сборку под свой мод.
- Релизы и артефакты теперь содержат и `config.launcher`, а CI дополнительно
  проверяет конфиги из репозитория через `--check-config`.
- Проверка обновлений использует репозиторий из конфига, а не константу в коде.

### Удалено

- Жёсткая таблица кнопок и привязка к файлам сборки CoC внутри Python-кода.

## [1.1.0] — 2026-09-15

### Добавлено

- **Автосборка `.exe`** через GitHub Actions: `Launcher-CoC.exe` собирается
  PyInstaller на `windows-latest` и публикуется в релизах — пользователю
  больше не нужен установленный Python (#11).
- Артефакт сборки при каждом пуше и pull request: файл можно скачать со
  страницы Actions и проверить без установки Python.
- **Атмосферный фон в стиле Зоны**: безрамочное окно с собственным заголовком,
  кнопками «свернуть/закрыть», перетаскиванием за заголовок (#8).
- **Иконка приложения** (`assets/icon.ico`, 16…256 px) для окна, панели задач
  и собранного `.exe`.
- Плавные анимации: подсветка кнопок при наведении, появление окна.

### Изменено

- Дизайн интерфейса переработан: тёмная «зональная» палитра, акцентная кнопка
  запуска, подписи режимов, статусная строка с состояниями (обычный/успех/ошибка).
- Кнопка «ОБНОВЛЕНИЕ» больше не заглушка: лаунчер в фоне проверяет последний
  релиз через GitHub API, сообщает о новой версии и открывает страницу релиза.
- Код разбит на пакет `launcher` (`paths`, `options`, `runner`, `updates`, `ui`),
  точка входа — `launcher_coc.py`.
- CI: `flake8` заменён на `ruff`, тесты — `pytest` (34 теста), сборка и тесты
  гоняются на каждый push и pull request.

### Удалено

- Файлы IDE (`.idea/`) больше не отслеживаются репозиторием.

## [1.0.0] — 2026-09-14

### Добавлено

- Первая версия лаунчера на **Python 3 + PySide6 (Qt 6)**: запуск игры,
  отладочный запуск (`-dbg`), фаст-запуск для слабых ПК, менеджер модов,
  настройки игры.
- Проверка наличия файлов перед запуском и понятные сообщения об ошибках.
- Логирование в `launcher.log`.
